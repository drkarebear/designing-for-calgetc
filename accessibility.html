Designed for usable access

Accessibility

The site is being built with semantic structure, keyboard access, visible focus, responsive layouts, reduced-motion support, descriptive links, and decorative imagery kept out of the accessibility tree.

Current practices

Skip links, semantic landmarks, heading hierarchy, keyboard-operable controls, responsive reflow, visible focus states, and reduced-motion support are built into the shared template.

Decorative assets

Mountain and poppy artwork is decorative and uses empty alternative text or CSS backgrounds so it does not add noise for screen-reader users.
