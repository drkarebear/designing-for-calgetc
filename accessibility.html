Designed for usable access

Accessibility

Designing for Cal-GETC aims to meet WCAG 2.2 Level AA and to remain usable with keyboard navigation, screen magnification, screen readers, and other assistive technology.

Accessibility statement

Accessibility commitment

This site is designed toward WCAG 2.2 Level AA. Accessibility is treated as an ongoing maintenance responsibility rather than a one-time certification.

Current accessibility practices

  • Semantic landmarks, one primary page heading, and structured section headings.
  • A skip link on every page and visible keyboard focus indicators.
  • Keyboard-operable native links, buttons, details disclosures, checkboxes, and selects.
  • Responsive layouts designed to reflow without requiring two-dimensional scrolling for ordinary page content.
  • Text and interactive-control contrast selected for WCAG 2.2 Level AA targets.
  • Reduced-motion support when the operating system requests reduced motion.
  • Decorative mountain and poppy artwork uses empty alternative text or CSS backgrounds.
  • Status changes in the Cal-GETC area checker are announced with live regions.

Review status

A sitewide source and interaction review was completed in September 2026, followed by a cognitive-accessibility pass focused on keyboard order, screen-reader structure, responsive reflow, long-page navigation, and reducing unnecessary decision density.

This is not a third-party accessibility certification. Final browser zoom, multiple screen-reader, magnifier, high-contrast, and disabled-user testing remains recommended.

Feedback

Report an accessibility issue

If something on this site is difficult to access or use, email Karen Crozer at karencrozer@gmail.com.

If possible, include the page you were using and a short description of the barrier. Information about your browser, device, or assistive technology is helpful but not required.

You may also use this address to request site content in a different accessible format.

Scope and external content

This accessibility commitment applies to the Designing for Cal-GETC website itself. The site links to external websites and official PDFs maintained by other organizations; their accessibility is outside this site’s control.

Independence

This is an independent faculty-created resource. It is not affiliated with or endorsed by the California Community Colleges Chancellor’s Office.
