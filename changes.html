Changes

Use this page when you remember a rule differently. We separate actual Version 1.4 revisions from older implementation guidance that may still circulate.

Current framework: Version 1.4

Version 1.4 was approved May 15, 2026. The current standards govern; older memos and reviewer notes remain useful only within their scope and should not override a newer standard.

Area 1A · Quantity of Writing

Current: minimum 5,000 words of scaffolded writing appropriate for academic contexts across major assignments. The former 4,000-word revised-final-draft language was removed in Version 1.4.

See Area 1A →

Cross-listed courses

Version 1.4 adds that cross-listing must already be approved locally before Cal-GETC submission, and the cross-listed CORs must be identical across specified elements.

Textbooks / equivalents

Version 1.4 clarifies required identification of textbooks/equivalents, treatment of OER and online texts, publication-date expectations, and lab manuals.

Existing approvals and re-review

Version 1.4 clarifies the phase-out process and provides time for a CCC to revise and resubmit a course that no longer meets the standard.

Primary source: ICAS, Cal-GETC Standards Version 1.4 Summary of Substantial Changes.
