Small data footprint by design

Privacy & Security

This independent faculty resource is intentionally built as a simple static website with no accounts, analytics, advertising, or server-side data collection features.

At a glance

What this site does not collect

No tracking

  • No analytics or tracking pixels
  • No advertising technology
  • No behavioral profiling or fingerprinting
  • No third-party scripts, fonts, or CDNs

No visitor accounts

  • No sign-in or user profiles
  • No passwords or authentication data
  • No forms that submit information to this site
  • No payment or transaction processing

No browser storage

  • No cookies set by site code
  • No localStorage or sessionStorage
  • No service worker
  • No saved checklist history

No hidden network calls

  • The interactive checker runs in your browser
  • Checklist selections are not sent anywhere
  • The site's Content Security Policy blocks script-initiated network connections

What happens when you use the Cal-GETC area checker?

Local to your browser

Your checkbox selections exist only in the currently open page. They are not uploaded, saved to browser storage, or sent to a database.

If you open the checker from an area guide, the selected area may appear after a # in the page address, such as #area=1a. That URL fragment is used by the browser to preselect the area and is not part of the HTTP request sent to the web server.

Printing or saving the checklist as a PDF uses your browser's own print function. The site does not receive the resulting file.

Hosting and routine connection data

Like any public website, the hosting provider receives the technical information needed to deliver pages over the internet, which can include an IP address, browser information, requested URL, and timing information. Designing for Cal-GETC does not include code to read, combine, profile, or analyze that information.

If the hosting platform changes, this statement should be reviewed so it continues to describe the site's actual behavior.

External links

Links to ICAS, ASSIST, CSU, UC, and other official resources leave this website. A no-referrer policy is used so this site does not intentionally tell those external sites which Designing for Cal-GETC page you came from.

Once you follow an external link, the destination site's own privacy and security practices apply.

Email contact

The email links on this site open your email application. Messages are not submitted through the website itself. If you email Karen Crozer, the message is handled by the email services used by you and the recipient.

The public contact address is karencrozer@gmail.com.

Security design

The production site uses only local HTML, CSS, JavaScript, and image files. It has no server-side application, database, package dependencies, embedded third-party content, or user-generated content.

A restrictive browser Content Security Policy allows scripts, styles, and images only from the site's own origin and blocks script-initiated network connections, frames, plugins, workers, and form submissions.

Questions or reports

Report a privacy or security concern

Email karencrozer@gmail.com. Please do not include passwords, student records, or other sensitive information in a report.

If the site later adds analytics, forms, external embeds, accounts, cloud storage, or other data-processing features, this privacy and security statement should be updated before those features are published.
